# Modal deployer

Private utility Space that deploys the Qwen Image Edit Rapid backend to
[Modal](https://modal.com) whenever it (re)starts, then pauses itself.
Restart the Space to redeploy. See the source repo:
[DE0CH/Qwen-Image-Edit-Rapid-AIO-GGUF](https://github.com/DE0CH/Qwen-Image-Edit-Rapid-AIO-GGUF)
